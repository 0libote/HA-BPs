## Themes

### Clean Home

A clean, high-readability Home Assistant theme with automatic light and dark modes, large labels, strong contrast and heavily rounded cards/controls.

- [Theme and installation guide](themes/clean-home/README.md)
- [Theme YAML](themes/clean-home/clean-home.yaml)
- [Example dashboard](themes/clean-home/example-dashboard.yaml)

The theme is designed to stay as native to Home Assistant as possible. HACS is not required for the main theme.
